# Learn C with K&R 2e

Working through the problem sets in *The C Programming Language, Second Edition* by Kernighan and Ritchie.

# Goal

The goal of this repo is to store and track my progress by writing out my own solutions to the problems and excercises in the book as I understand them
and improving my understanding of C by following along with the book chapter by chapter.

## Structure

- `chapter-01/`
- `chapter-02/`
- `chapter-03/`
- ...
- `chapter-08/`

Each chapter folder may include exercise solutions helper programs notes and comments
and anything I end up putting in there for whatever reason.

## How to use

Build and run any program with your preferred C compiler.
